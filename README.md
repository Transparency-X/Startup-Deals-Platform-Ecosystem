## Executive Summary

This repository provides a **structured, region-aware comparison** of platforms that aggregate startup deals, SaaS credits, and founder perks. Unlike generic lists, this report prioritises:

- **Geographic specificity** — Whether a platform serves Ireland (IE), Northern Ireland / UK (NI/UK), EU/Europe, USA/Canada, or APAC
- **Currency transparency** — Exact pricing in EUR, GBP, and USD where available
- **Risk assessment** — Continuity risk for lifetime deals (LTDs) and vendor stability
- **Stacking guidance** — How to legally combine multiple programs for maximum runway

> **Key Insight:** The largest startup value does not come from paid aggregators. Direct vendor programs (Microsoft Founders Hub, Google for Startups, AWS Activate) collectively offer **$500,000–$700,000** in free credits — all without membership fees. Apply to these **before** considering paid platforms.

## Stacking Strategy Guide

> **Stacking = legally combining multiple programs for maximum value.**

### Example Stack: AI Startup in Ireland

| Layer | Program | Value | Currency |
|:---|:---|:---|:---|
| **Cloud (Primary)** | Google for Startups AI track | $350,000 | USD credits |
| **Cloud (Secondary)** | Microsoft Founders Hub | $150,000 | USD credits |
| **Cloud (Tertiary)** | AWS Activate (Portfolio) | $100,000 | USD credits |
| **Dev Tools** | GitHub Enterprise (via Microsoft) | $252/yr | USD |
| **Productivity** | Notion for Startups (6 mo free) | ~$500 | USD |
| **CRM** | HubSpot for Startups (90% off Y1) | ~$5,000 | USD |
| **Communications** | Twilio Startups | $5,000 | USD credits |
| **Database** | MongoDB for Startups | $10,000 | USD credits |
| **Email** | SendGrid for Startups (12 mo) | ~$2,400 | USD |
| **Banking** | Ramp via Stripe Atlas | $500 bonus | USD |
| **Aggregator** | Secret (for remaining SaaS) | Variable | USD |
| **TOTAL POTENTIAL** | | **~$623,000+** | |

### Stacking Rules

1. **Cloud credits can stack across providers** — Google, Microsoft, and AWS credits are independent
2. **Same-provider credits may NOT stack** — AWS credits from Stripe Atlas + FounderPass may conflict; confirm with AWS
3. **SaaS deals from aggregators stack with direct programs** — Secret deal for Notion stacks with Notion for Startups direct
4. **Always read terms of service** — Some programs prohibit "double-dipping" on the same tool
5. **Document everything** — Create a spreadsheet tracking claim dates, expiry, and T&Cs
